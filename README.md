## How to run

1. Open [Google Colab](https://colab.research.google.com) → **New notebook**.
2. Upload the relevant file(s) from `datasets/` (see table below) using the folder
   icon on the left, **or** just run the cell — every script regenerates its own
   data automatically if the file isn't found (except the two diabetes CSVs and
   `iris_dataset.csv`, which ship with the package since the univariate/bivariate/
   time-series stats must match a fixed dataset across experiments 3–5).
3. Paste the entire contents of `DAV_Lab_Exp<N>_code/exp<N>_*.py` into **one** cell
   and run it.

## Datasets

| File | Used by | Source |
|---|---|---|
| `pima_diabetes.csv` | 3A–5C | **Real** Pima Indians Diabetes Database (Sigillito, Johns Hopkins/NIDDK, 1990) — 768 rows, 9 columns. Fetched from `raw.githubusercontent.com/jbrownlee/Datasets`. |
| `uci_diabetes.csv` | 3A–5C | Synthetic same-schema cohort (jittered resample of the Pima data, seed=7) built so the manual's two-dataset comparison procedure has something distinct to compare against. **Replace with your actual UCI file for submission** if your course provides one — the real UCI diabetes dataset (sklearn's `load_diabetes`) uses a different schema (10 physiological features, no `Outcome`), so it doesn't drop in as a like-for-like replacement without rewriting the feature lists in 3A/3B/3C/4A–4D. |
| `iris_dataset.csv` | 2D | `sklearn.datasets.load_iris()`, exported to CSV — the real, standard 150-row Iris dataset. |
| `sales_data.csv` / `.xlsx` | 2B, 2C | Synthetic 40-row order dataset generated for the Pandas/file-reading exercises (no public order dataset was specified in the manual). |
| `diabetes_timeseries.csv` | 5C | The Pima `Glucose` column reused as a sequential series, exactly as the manual's `diabetes9.csv` does. |

## Verification

The Pima-side output of Experiment 3B (`R² = 0.0489` for Glucose→BMI) was checked
against the reference screenshot and matches exactly, confirming this package uses
the same underlying Pima Indians Diabetes data as the manual's own sample output.

Every chart in every `*_op/` folder was generated by **actually running** the
corresponding code in a Python 3.12 environment (pandas / numpy / scipy /
matplotlib / seaborn / scikit-learn / statsmodels) — none of the images are
mock-ups. Minor numeric differences from any output already in your notebook are
expected wherever `train_test_split` uses a different `random_state`, or wherever
your own dataset file differs from the ones bundled here.

## Corrections applied to the lab manual code

| Exp | Note |
